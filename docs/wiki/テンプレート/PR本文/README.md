# PR 本文

PR の種類ごとに書式が分かれる。
レイヤーの面（ベース PR）は要件を持ち、その配下の成果物 PR は作業の To Do と結果を持つ。

## 目次

| ページ | 対象 PR | 概要 |
| --- | --- | --- |
| [システムベース](./システムベース.md) | `docs/system/{ドメイン}/base` の PR | 構成要件 + エピック一覧 |
| [エピックベース](./エピックベース.md) | `{type}/epic/{ドメイン}/base` の PR | ユースケース一覧 + 横断要件 + PoC 結果 |
| [ストーリーベース](./ストーリーベース.md) | `{type}/story/{ドメイン}/{UC名}/base` の PR | ユースケース要件 + サブシステム一覧 |
| [サブシステムベース](./サブシステムベース.md) | `{type}/{scope}/{ドメイン}/{UC名}/base` の PR | 現状 + システム要件（SA） |
| [成果物](./成果物.md) | 土台生成 / シナリオ / 設計 / 実装 / RE / バグ修正 の成果物 PR | 紐づく Issue + タスク一覧 |
| [モック](./モック.md) | `docs/epic/{ドメイン}/mock` の PR | タスク一覧 + UI 設計 |
| [統合テスト](./統合テスト.md) | `test/epic/.../integration` / `test/story/.../integration` の PR | タスク一覧 + シナリオテスト結果 |
| [単体・結合テスト](./単体・結合テスト.md) | `test/{scope}/{ドメイン}/{UC名}/{変更内容}` の PR | タスク一覧 + 単体 / 結合テスト結果 |
| [エピックPoC](./エピックPoC.md) | `poc/epic/{ドメイン}/{テーマ}` の PR（マージせず close） | リスク仮説 + 検証構成 + 成功条件 + 検証結果 + 最小再現コード |
| [ライブラリPoC](./ライブラリPoC.md) | `poc/{scope}/{ドメイン}/{UC名}/{lib名}` の PR（マージせず close） | 検証対象 + 調査結果 + 検証観点と結果 |
