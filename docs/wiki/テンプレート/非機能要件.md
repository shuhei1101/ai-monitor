# ai-monitor テンプレート: 非機能要件

外部コンポーネントの制約を踏まえて、アプリとして守る値を決める書式。
「外部がどこまで許すか」ではなく「自分たちが実際にどこで止めるか」を確定させる。

配置先は `docs/wiki/設計図/非機能要件.md`（1 プロジェクト 1 ファイル・フォルダは切らない）。

外部の制約そのものは `外部API/{名前}.md` / `外部ライブラリ/{名前}.md` が持ち、本ページはそれを引いた決定値を持つ。
Issue 側の非機能要件（epic の `## 横断要件` / subsystem の `### 非機能要件`）は「こうしたい」という要求で、本ページは「外部制約を踏まえてこう決めた」という決定を扱う。

本ページの 1 行が非機能要件テスト 1 ケースと対応する。

## セクション一覧

| セクション | サブセクション | 必須or条件 | 担当 | 補足 |
| --- | --- | --- | --- | --- |
| `## 決定値一覧` | - | 必須 | system-architect が初版、以降は各レイヤーが追記 | 1 行 = 非機能要件テスト 1 ケース |
| `## 未確定` | - | 決定できない項目がある場合 | 同上 | 決められない理由と決める条件を残す |

## `## 決定値一覧`

外部の制約から逆算したアプリ側の値を並べる。

### 記述例

```markdown
## 決定値一覧

| カテゴリ | 項目 | 外部の制約 | 出所 | アプリの決定値 | 根拠 | 対応テスト | 補足 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 性能 | 1 リクエストの画像枚数 | 50 枚 / リクエスト | [外部API/OpenAI](../外部API/OpenAI.md) | 40 枚 | 失敗時の再送で 10 枚分の余地を残す | `tests/nfr/test_image_batch.py` | - |
| 性能 | 入力トークン上限 | 100 万トークン | [外部API/OpenAI](../外部API/OpenAI.md) | 10 万トークン | 内部システムプロンプトと出力枠を差し引く | `tests/nfr/test_input_limit.py` | - |
| レート制限 | API 呼び出し間隔 | 5000 req / 時 | [外部API/GitHub](../外部API/GitHub.md) | 15 秒に 1 回 | 複数プロジェクトの同時監視でも上限の 1/5 に収まる | `tests/nfr/test_poll_interval.py` | - |
| 可用性 | 外部障害時の挙動 | SLA 99.9% | [外部API/OpenAI](../外部API/OpenAI.md) | 3 回リトライ後に待機 | 月 43 分の停止を待機で吸収する | `tests/nfr/test_retry.py` | - |
| 保守性 | ログ保存期間 | 制限なし | - | 30 日 | 障害調査に必要な期間として設定 | - | 外部制約なしの自主基準 |
```

### 補足

**カテゴリ列:**
- 性能 / レート制限 / 可用性 / 耐障害 / セキュリティ / コスト / 保守性 など。
  プロジェクト固有のカテゴリを足してよい

**項目列:**
- 何についての値かを 1 行で。
  同じカテゴリに複数の項目が来る場合は 1 項目 = 1 行に分ける

**外部の制約列:**
- 外部が提示している上限・下限・保証値をそのまま書く。
  外部制約が無い自主基準の行は `制限なし`

**出所列:**
- 制約の根拠になったページへのリンク（`外部API/{名前}.md` / `外部ライブラリ/{名前}.md`）。
  外部制約が無い行は `-`

**アプリの決定値列:**
- 実装とテストが参照する確定値。
  単位まで書く

**根拠列:**
- なぜ外部の制約そのままではなくその値にしたかを 1 行で。
  余裕を取る / 内訳を差し引く / 運用上の都合 などを具体的に書く

**対応テスト列:**
- その決定値を検証する非機能要件テストのファイルパス。
  テストで測れない項目は `-`

**補足:**
- 外部ライブラリ / 外部 API を新規採用したときは、その制約から決まる行を本表に追加する
- 決定値を変えるときは根拠列も同時に更新する

## `## 未確定`

決めたいが決められない項目を残す。

### 記述例

```markdown
## 未確定

| カテゴリ | 項目 | 決められない理由 | 決める条件 | 補足 |
| --- | --- | --- | --- | --- |
| 性能 | 同時接続数 | 想定利用者数が未確定 | epic「利用者管理」の要件確定後 | - |
| コスト | 月次の API 予算 | 銘柄が未定 | 認証基盤の subsystem で銘柄が決まった後 | - |
```

### 補足

**決められない理由列:**
- 何が分かれば決まるのかが読み取れるように書く

**決める条件列:**
- 決定を待っている工程・Issue を指す。
  その工程が終わったら決定値一覧へ移す

**補足:**
- 決まった項目は本セクションから消して `## 決定値一覧` に移す
- 未確定が 1 件も無い場合はセクションを残して「なし」とだけ記載する
