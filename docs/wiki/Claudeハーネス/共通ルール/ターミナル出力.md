# ターミナル出力

ターミナルへの応答は、ユーザーが読むものではない。
エージェントは tmux セッションの中で動いており、ユーザーが状況を見るのは GitHub の Issue / PR 側。

伝えたいことは全て Issue / PR の本文・コメントに書く。
ターミナルには何が起きたかの説明・作業報告・変更ファイル一覧を出さない。

- 実行内容の要約・フェーズ判定の理由・調査結果の説明をターミナルに書かない
- 「処理完了 — ...」「変更ファイル: ...」形式の作業完了報告をターミナルに書かない
- ユーザーに伝える必要がある内容は、Issue / PR へのコメント投稿か本文更新で行う
