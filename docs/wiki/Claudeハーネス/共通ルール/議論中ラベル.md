# 議論中ラベル

`議論中` はユーザーとの議論が開いていることを示すラベル。
待機に入るとき（`assignee=ユーザー` の設定と同時に）付与するのはエージェントだが、外せるのはユーザーだけ。

- 除去は MCP が拒否する（`transition_phase` / `remove_labels` の対象外）。承認をエージェント側で作れないようにするため
- フェーズの起動条件にある「`議論中` なし」は、ユーザーが外した結果として成立する。条件を満たすために自分で外しにいかない
- ユーザーがまだ外していないなら、その面はユーザーの番。待機を続けるか、届いたフィードバックに応答ループで対応する
