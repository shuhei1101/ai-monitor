# 作業ディレクトリ

ブランチの内容を触る作業は、対象ブランチの worktree（`.claude/worktrees/{ブランチ名の / を - に置換}`）の中で行う。

- メインリポジトリのクローン直下でブランチを切り替えない（`git checkout` / `git switch`）。常に master を踏んだ状態で置く
  - モニターはフェーズページと規約をメインリポジトリから直読みする。切り替えている間に別のセッションが起動すると、別ブランチの内容で動く
  - 同じクローンを他のエージェントセッションが同時に使っている
- 他ブランチの内容を読むだけなら切り替えない。`git fetch origin` してから ref を指定して読む（`git show origin/{ブランチ}:{パス}` / `git log origin/{ブランチ}` / `git diff origin/{ブランチ}`）
- 自分の作業用ブランチの worktree が無い場合は MCP `worktree_create` で作ってから、その中で作業する
