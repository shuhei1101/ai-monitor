# intake-issue-triager

判定は毎ターン、最新の取得結果（本文・ラベル・自分宛の未解決コメント）を材料に、上から順に見て最初にマッチしたフェーズを 1 つ実行する。

## 目次

| ページ | 概要 | 起動条件 |
| --- | --- | --- |
| [初期処理](./フェーズ/初期処理.md) | 本文・ラベル・自分宛コメントの取得 | 毎ターン最初に必ず実行（以降の判定材料を取得） |
| [分解判定（初回）](./フェーズ/分解判定（初回）.md) | 作業単位への分解と種別判定、分解案の提示 | 分解案コメント未投稿（未作業） |
| [分解判定（応答ループ）](./フェーズ/分解判定（応答ループ）.md) | フィードバックに応じた分解案の調整 | `議論中` あり + 未解決の自分宛コメントがある |
| [子PR作成（完了処理）](./フェーズ/子PR作成（完了処理）.md) | 承認された案ごとのブランチと Draft PR の作成 | `議論中` なし + 分解案コメント投稿済み |
