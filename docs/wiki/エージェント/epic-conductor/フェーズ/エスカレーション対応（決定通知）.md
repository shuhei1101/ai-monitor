# エスカレーション対応（決定通知）

エスカレーション対応で指示した複合シナリオ修正の完了を受けて、発生元の story へ決定を降ろす。

## 手順

### 修正内容の確認

complex-scenario-writer の完了報告のコミット表から差分を取得し（共通ルール『PR差分の取得』）、指示した方針が複合 UC シナリオに反映されているかを照合する。

### 完了報告の Resolve

MCP `resolve_comments` を呼ぶ:
- `node_ids`: complex-scenario-writer の完了報告コメントの `node_id`

### 発生元 story への決定通知

MCP `comment` を呼ぶ:
- `number`: 発生元の story PR 番号
- `is_pr`: true
- `sender`: `epic-conductor`
- `receiver`: `story-conductor`
- `format`:
  - `type`: `plain`
  - `body`: 決定した方針・変更した epic 本文の箇所・修正後の複合 UC シナリオのページ名・それを踏まえて再開してほしい作業

続けて MCP `add_labels` を呼ぶ:
- `number`: 発生元の story PR 番号
- `is_pr`: true
- `labels`:
  - `$AI_MONITOR_LABEL_CONFIRM_STORY_CONDUCTOR` の値

### ラベル除去

MCP `transition_phase` を呼ぶ:
- `number`: $number
- `is_pr`: true
- `remove_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_EPIC_CONDUCTOR` の値
- `add_labels_`: なし

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `epic-conductor`
- `number`: $number
