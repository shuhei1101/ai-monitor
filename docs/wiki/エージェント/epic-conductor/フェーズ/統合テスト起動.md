# 統合テスト起動

story-conductor の完了報告（story 完了）を受けて全子 story の close 状態を確認し、全完了なら複合 UC 統合テスト一式を complex-scenario-writer に委任する。
統合テストの内部工程（実装 → レビュー → 実行）は writer が指揮する。

## 手順

### 全子 story の確認

初期処理で取得した Sub-issue の state を確認する。

### 完了報告の Resolve と分岐

MCP `resolve_comments` で story-conductor の完了報告コメントを Resolve する。

- 全子 story が closed の場合、「統合テストの成果物 PR の用意」へ進む
- open の story が残っている場合、open の各 story PR に状況確認を送り、「ラベル除去」へ飛ばす（残りの story の完了報告で再復帰する。「統合テストの成果物 PR の用意」「complex-scenario-writer への委任」は実行しない）:
  1. MCP `comment` を呼ぶ（`number`: open の story PR 番号・`is_pr`: true・`sender`: `epic-conductor`・`receiver`: `story-conductor`・`format`: `type` が `plain` で `body` が 進捗とブロッカーの確認）
  2. MCP `add_labels` を呼ぶ（`number`: open の story PR 番号・`is_pr`: true・`labels`: `$AI_MONITOR_LABEL_CONFIRM_STORY_CONDUCTOR` の値）

### 統合テストの成果物 PR の用意

統合テストは epic ブランチ直下の成果物ブランチで行う（規約『ブランチ戦略』の成果物ブランチ）。

- 成果物 PR が既に open の場合（バグ修正後の再テスト）は作り直さず、その PR を委任先にして「complex-scenario-writer への委任」へ進む

自分の epic ブランチ名 `{type}/epic/{ドメイン}/base` からドメイン部を取り出して成果物ブランチを組み立てる。

MCP `worktree_create` を呼ぶ:
- `branch`: `test/epic/{ドメイン}/integration`
- `base_ref`: `origin/{自分の epic ブランチ}`

続けて MCP `create_draft_pr` を呼ぶ:
- `head_branch`: 作成したブランチ
- `base_branch`: 自分の epic ブランチ
- `title`: `{epic のタイトル}（複合ユースケース統合テスト）`
- `body`: `## 紐づく Issue`（epic PR と同じ起点の Issue 番号）と `## タスク一覧`
- `labels`: `$AI_MONITOR_LABEL_TYPE_TEST` の値

`## タスク一覧` は E2E テストコードの作成とテストの実行を行に分けて列挙する（書式はテンプレート「PR本文/統合テスト」）。
チェックは各行を担当した作業者が入れるので、ここでは全行を未チェックで作る。

続けて MCP `add_watch_targets` を呼ぶ:
- `agent_name`: `epic-conductor`
- `number`: $number
- `watch_numbers`: 作成した PR の番号

### complex-scenario-writer への委任

MCP `comment` を呼ぶ:
- `number`: 統合テストの成果物 PR の番号
- `is_pr`: true
- `sender`: `epic-conductor`
- `receiver`: `complex-scenario-writer`
- `format`:
  - `type`: `plain`
  - `body`: 委任の経緯（初回実装か、バグ修正後の再テストか）

続けて MCP `add_labels` を呼ぶ:
- `number`: 統合テストの成果物 PR の番号
- `is_pr`: true
- `labels`:
  - `$AI_MONITOR_LABEL_CONFIRM_COMPLEX_SCENARIO_WRITER` の値

初回実装か再テストかの判定は writer がテスト結果表で行う。

### ラベル除去

MCP `transition_phase` を呼ぶ:
- `number`: $number
- `is_pr`: true
- `remove_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_EPIC_CONDUCTOR` の値
- `add_labels_`: なし（ユーザー承認なしの自動完了）

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `epic-conductor`
- `number`: $number
