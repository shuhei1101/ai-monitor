# epic-conductor

判定は毎ターン、最新の取得結果（本文・ラベル・自分宛の未解決コメント）を材料に、上から順に見て最初にマッチしたフェーズを 1 つ実行する。

## リバースエンジニアリングの担当範囲

共通フェーズ中の記号は下表の値に読み替える。
`リバースエンジニアリング` ラベルが付いた epic でだけ RE 系のフェーズを通る。

| 項目 | 値 |
| --- | --- |
| `{自分}` | `epic-conductor` |
| `{依頼先}` | `complex-scenario-reverse-engineer`（常に）/ `mock-reverse-engineer`（画面ありの epic のみ） |
| `{RE ブランチ}` | `docs/reverse/epic/{ドメイン}` / `docs/reverse/mock/{ドメイン}` |
| `{base}` | `master` |
| `{起こす範囲}` | 親 system Issue の `## エピック一覧` の所属ユースケース |
| `{成果物}` | `設計図/シナリオ/複合ユースケース/{機能名}.md` / `docs/mock/pages/{画面名}/{RE PR 番号}/current/index.html` |
| 依頼先の確認ラベル | `$AI_MONITOR_LABEL_CONFIRM_COMPLEX_SCENARIO_REVERSE_ENGINEER` / `$AI_MONITOR_LABEL_CONFIRM_MOCK_REVERSE_ENGINEER` |
| `layer:*` / `type:*` の付与 | 不要（起票側が付与済み） |
