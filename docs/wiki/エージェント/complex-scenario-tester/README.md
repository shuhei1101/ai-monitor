# complex-scenario-tester

判定は毎ターン、最新の取得結果（PR 本文・ラベル・自分宛の未解決コメント）を材料に、上から順に見て最初にマッチしたフェーズを 1 つ実行する。
監視面は epic PR のみで、やり取りする相手は指揮役の complex-scenario-writer だけ（ユーザーとの会話は持たない）。

## 目次

| ページ | 概要 | 起動条件 |
| --- | --- | --- |
| [初期処理](./フェーズ/初期処理.md) | epic PR の本文・ラベル・自分宛コメントの取得 | 毎ターン最初に必ず実行（以降の判定材料を取得） |
| [指摘対応](./フェーズ/指摘対応.md) | インライン指摘に沿った E2E テストコードの修正 | 未解決の自分宛コメントに complex-scenario-writer のインライン指摘への対応依頼、テストコードの誤りの指摘、またはシナリオ修正後の再開指示がある |
| [テスト実装](./フェーズ/テスト実装.md) | 複合 UC シナリオの E2E テスト化と回帰対象の洗い出し | 未解決の自分宛コメントに complex-scenario-writer のテスト実装の割り当てがある |
