# 指摘対応

single-scenario-writer のインライン指摘に沿って E2E テストコードを修正し、同じスレッドに返信して再レビューに戻す。

## 手順

### 指摘の取得

MCP `list_review_threads` を呼ぶ:
- `pr_number`: $pr_number
- `include_resolved`: false

各スレッドの `path` / `line` / `diff_hunk` / 本文から、指摘対象の箇所と期待する修正を把握する。

### E2E テストコードの修正

story ブランチの worktree へ移動し、`git pull --ff-only` でリモートの最新を取り込む。

指摘 1 件ずつ修正して commit push する。

- 回帰対象の追加を求める指摘の場合、対象のテストを洗い出してテスト結果表の行も足す

### テスト結果表の更新

テストファイルや回帰対象の増減を伴う修正だった場合、story PR 本文の `## 単一ユースケースシナリオテスト結果` の行を実態に合わせる。

MCP `update_body` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `body`: 更新後本文

### 対応依頼への返信

MCP `reply_comment` を呼ぶ:
- `comment_node_id`: single-scenario-writer の対応依頼コメントの node_id
- `sender`: `single-scenario-tester`
- `receiver`: `single-scenario-writer`
- `format`:
  - `type`: `commits`
  - `body`: 修正完了の報告（指摘ごとの対応内容）
  - `entries`: 積んだ commit の `commit` と `summary` の組

### ラベル遷移

MCP `transition_phase` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `remove_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_SINGLE_SCENARIO_TESTER` の値
- `add_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_SINGLE_SCENARIO_WRITER` の値

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `single-scenario-tester`
- `number`: $pr_number
