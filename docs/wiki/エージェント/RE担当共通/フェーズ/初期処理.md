# 初期処理

毎ターン最初に必ず実行する。
`{自分}` はフェーズ索引の 1 行目に書かれた自分のエージェント名に読み替える。

## 手順

### RE PR の最新状態の取得

MCP `get_issue_or_pr` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true

続けて MCP `list_comments` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `addressee`: `{自分}`
- `include_resolved`: false

### 紐づく Issue の取得

RE PR 本文の `## 紐づく Issue` から Issue 番号を取り出す。

MCP `get_issue_or_pr` を呼ぶ:
- `number`: 取り出した Issue の番号
- `is_pr`: false
- `comments`: false

### フェーズの決定

フェーズ索引のフェーズ一覧を上から順に見て、起動条件に最初にマッチしたフェーズの手順を実行する。
前ターンの記憶ではなく取得結果を判定材料にする。
