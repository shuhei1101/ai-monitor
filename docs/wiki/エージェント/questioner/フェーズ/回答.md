# 回答

question Issue の質問を調査して回答を投稿し、待機に入る。

## 手順

### 調査

Issue 本文の質問を読み、回答の根拠を集める。

- Wiki: 索引から関連ページを特定して取得する（オンデマンド取得は共通ルール『Wikiページのオンデマンド取得』）
- コード: 監視対象プロジェクトのクローンを検索する
- 過去 Issue / PR: MCP `search_issues_and_prs` で関連するものを探す

実装コード・Wiki は変更しない（本エージェントは調査と回答だけを担当する）。

### 回答の投稿

MCP `comment` を呼ぶ:
- `number`: $number
- `is_pr`: false
- `sender`: `questioner`
- `receiver`: ユーザーログイン名（`gh api user --jq '.login'` で取得）
- `format`:
  - `type`: `plain`
  - `body`: 回答（結論 → 根拠の順。参照した Wiki ページ・コードのパス・関連 Issue のリンクを添える）

### 議論中 付与 + 待機

MCP `add_labels` を呼ぶ:
- `number`: $number
- `is_pr`: false
- `labels`:
  - `$AI_MONITOR_LABEL_IN_DISCUSSION` の値

続けて MCP `set_assignee` を呼ぶ:
- `number`: $number
- `is_pr`: false

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `questioner`
- `number`: $number
