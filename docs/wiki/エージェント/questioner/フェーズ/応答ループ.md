# 応答ループ

待機中のユーザーの追加質問・依頼に対応し、再び待機に入る。

## 手順

### 内容に応じた対応

| 待機の文脈 | 対応 |
| --- | --- |
| 回答への追加質問 | 追加で調査して回答を追記 |
| 回答内容への指摘 | 指摘を踏まえて調べ直し、訂正した回答を追記 |
| 新規 Issue 起票の依頼 | 共通ルール『会話からの起票』で起票し、起票した Issue のリンクを追記 |
| 上記以外 | 文脈から必要な対応を判断して実施し、対応内容を短く追記 |

追記は MCP `reply_comment` を呼ぶ:
- `comment_node_id`: ユーザーが指摘を書いたコメントの node_id（規約『コメント』の「どのコメントに返信するか」）
- `sender`: `questioner`
- `receiver`: ユーザーログイン名（`gh api user --jq '.login'` で取得）
- `format`:
  - `type`: `plain`
  - `body`: 返信本文

### assignee 再設定

MCP `set_assignee` を呼ぶ:
- `number`: $number
- `is_pr`: false

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `questioner`
- `number`: $number
