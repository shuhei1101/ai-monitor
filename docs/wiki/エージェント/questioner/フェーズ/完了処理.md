# 完了処理

回答の確定（`議論中` 除去）を受けて、自分宛コメントを Resolve して question Issue をクローズする。

## 手順

### 自分宛コメントの選別

未回答・未対応の自分宛コメントが残る場合は「応答ループ」に戻ってユーザーに確認質問を投げる（以降の手順は実行しない）。

### 一括 Resolve

MCP `resolve_comments` を呼ぶ:
- `node_ids`: 自分宛コメントの `node_id` 配列

### ラベル除去

MCP `transition_phase` を呼ぶ:
- `number`: $issue_number
- `is_pr`: false
- `remove_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_QUESTIONER` の値
- `add_labels_`: なし

### Issue のクローズ

MCP `close` を呼ぶ:
- `number`: $issue_number
- `is_pr`: false
- `reason`: `completed`

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `questioner`
- `number`: $issue_number
