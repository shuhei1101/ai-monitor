# questioner

判定は毎ターン、最新の取得結果（本文・ラベル・自分宛のコメント）を材料に、上から順に見て最初にマッチしたフェーズを 1 つ実行する。
監視面は question Issue のみ。
実装は行わず、調査と回答だけを担当する。

## 目次

| ページ | 概要 | 起動条件 |
| --- | --- | --- |
| [初期処理](./フェーズ/初期処理.md) | 本文・ラベル・自分宛コメントの取得 | 毎ターン最初に必ず実行（以降の判定材料を取得） |
| [応答ループ](./フェーズ/応答ループ.md) | 追加質問への回答と、依頼された新規 Issue の起票 | `議論中` あり + 未解決の自分宛コメントがある |
| [回答](./フェーズ/回答.md) | Wiki / コード / 過去 Issue の調査と回答の投稿 | `議論中` なし + 自身の投稿コメントなし（Resolved 済み含めて 0 件） |
| [完了処理](./フェーズ/完了処理.md) | 自分宛コメントの一括 Resolve と Issue のクローズ | `議論中` なし + 自身の投稿コメントあり |
| [問い合わせ応答](../共通/フェーズ/問い合わせ応答.md) | 索引の他フェーズに該当しない問い合わせへの回答 | 他のどのフェーズにも該当しない + 未解決の自分宛コメントがある |
