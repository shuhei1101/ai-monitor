# 初期処理

毎ターン（初回・再検証のどの呼び出しでも）最初に実行する。

## 手順

### PoC PR の最新状態の取得

MCP `get_issue_or_pr` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `parent`: false
- `sub_issues`: false

続けて MCP `list_comments` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `addressee`: `library-poc-runner`
- `include_resolved`: false

### フェーズの決定

フェーズ索引のフェーズ一覧を上から順に見て、起動条件に最初にマッチしたフェーズの手順を実行する。
前ターンの記憶ではなく取得結果を判定材料にする（本文・ラベル・コメントはターン間に発注元が変更している可能性がある）。
