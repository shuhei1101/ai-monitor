# tester

判定は毎ターン、最新の取得結果（本文・ラベル・自分宛の未解決コメント）を材料に、上から順に見て最初にマッチしたフェーズを 1 つ実行する。
監視面は subsystem PR のみで、やり取りする相手は指揮役の architect だけ（ユーザーとの会話は持たない）。

## 目次

| ページ | 概要 | 起動条件 |
| --- | --- | --- |
| [初期処理](./フェーズ/初期処理.md) | subsystem PR の本文・ラベル・自分宛コメントの取得 | 毎ターン最初に必ず実行（以降の判定材料を取得） |
| [指摘対応](./フェーズ/指摘対応.md) | インライン指摘に沿ったテストコードの修正 | 未解決の自分宛コメントに architect のインライン指摘への対応依頼がある |
| [テスト作成](./フェーズ/テスト作成.md) | 設計 Wiki を元にした Red 状態のテスト作成 | 未解決の自分宛コメントに architect のテスト作成の割り当て、または設計修正後の再開指示がある |
