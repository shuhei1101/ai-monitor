# single-scenario-writer

判定は毎ターン、最新の取得結果（PR 本文・ラベル・自分宛のコメント）を材料に、上から順に見て最初にマッチしたフェーズを 1 つ実行する。

## 目次

| ページ | 概要 | 起動条件 |
| --- | --- | --- |
| [初期処理](./フェーズ/初期処理.md) | 本文・ラベル・自分宛コメントの取得 | 毎ターン最初に必ず実行（以降の判定材料を取得） |
| [シナリオ修正](./フェーズ/シナリオ修正.md) | エスカレーション対応で決まった方針でのシナリオ修正と親 story Issue への完了報告 | 未解決の自分宛コメントに story-conductor のシナリオ修正指示がある |
| [統合テストレビュー](./フェーズ/統合テストレビュー.md) | E2E テストコードと実行対象のシナリオとの照合 | 未解決の自分宛コメントに single-scenario-tester のテスト実装完了報告がある |
| [テスト結果の判定](./フェーズ/テスト結果の判定.md) | 全 pass の完了報告 or fail のトリアージ | 未解決の自分宛コメントに single-scenario-tester の実行報告（全 pass or fail）がある |
| [シナリオ修正の再開指示](./フェーズ/シナリオ修正の再開指示.md) | 承認されたシナリオ修正での tester への再開指示 | `議論中` なし + 失敗報告スレッドに自分の修正報告を返信済み（未 Resolve） |
| [シナリオ作成（初回）](./フェーズ/シナリオ作成（初回）.md) | 単一ユースケースシナリオの設計と story ブランチへの commit | `議論中` なし + 自身の投稿コメントなし（Resolved 済み含めて 0 件） |
| [応答ループ](./フェーズ/応答ループ.md) | フィードバックに応じたシナリオ md の修正 push | `議論中` あり + 未解決の自分宛コメントがある |
| [完了処理](./フェーズ/完了処理.md) | 確認ラベルの除去と親 story Issue への引き継ぎ | `議論中` なし + 未 Resolve の自身の投稿コメントあり |
| [再テストの実行指示](./フェーズ/再テストの実行指示.md) | バグ修正後のレビュー済みテストの再実行指示 | `議論中` なし + 未解決の自分宛コメントなし + テスト結果表に `❌` の記録あり |
| [統合テスト割り当て](./フェーズ/統合テスト割り当て.md) | tester へのテスト実装タスクの割り当て | `議論中` なし + 未解決の自分宛コメントなし + テスト結果表が未記入 |
