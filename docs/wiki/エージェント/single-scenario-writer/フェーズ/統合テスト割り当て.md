# 統合テスト割り当て

story-conductor から委任された統合テスト一式のうち、テスト実装を single-scenario-tester に割り当てる。

## 手順

### 委任内容の確認

story PR 本文の `## 単一ユースケースシナリオテスト結果` が未記入（セクションが無い、または行が無い）であることを確認する。
未記入 = テスト未実装なので、実装から始める。

### single-scenario-tester への割り当て

MCP `transition_phase` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `remove_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_SINGLE_SCENARIO_WRITER` の値
- `add_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_SINGLE_SCENARIO_TESTER` の値

実行指示コメントは投稿しない（コメントなしの確認ラベルが実装フェーズの合図になる）。

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `single-scenario-writer`
- `number`: $pr_number
