# 完了処理

シナリオ合意（`議論中` 除去）を受けて、PR の `確認:single-scenario-writer` を除去し、親 story PR に確認ラベルを渡して役割を終える。

## 手順

### 自分宛コメントの選別

未回答・未対応の自分宛コメントが残る場合は「応答ループ」に戻ってユーザーに確認質問を投げる（以降の手順は実行しない）。

未解決のインライン確認事項スレッドが残っている場合も同じ扱いにする（応答ループの「決着したスレッドの Resolve」で畳めなかったものが該当する）。
決めきれていない論点を残したまま次工程へ渡さない。
- 回答なしで `議論中` を外されたのが 2 回目以降の場合は、推奨案への承認とみなして応答ループへ戻さず先へ進む（共通ルール『議論中ラベル』の「回答なしで外されたとき」）

### 一括 Resolve

MCP `resolve_comments` を呼ぶ:
- `node_ids`: 自分宛コメントの `node_id` 配列

### タスク一覧の確認

成果物 PR 本文の `## タスク一覧` のうち、自分が作成 / 更新した単一 UC シナリオとシナリオ索引の行がチェック済みかを確認する（チェックは commit 直後に入れている）。
応答ループで積んだ commit の分が未チェックなら、ここで `[x]` にする。
チェックを入れるのは作業した本人なので、E2E テストの行には触れない。

MCP `update_body` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `body`: 更新後本文

- PR 本文に `## タスク一覧` が無い場合、本手順は実行しない（シナリオ影響なしで通過した epic / story が該当する）

### 完了報告の投稿

初期処理で取得した `parent` から親 story PR 番号を得る。

MCP `comment` を呼ぶ:
- `number`: 親 story PR 番号
- `is_pr`: true
- `sender`: `single-scenario-writer`
- `receiver`: `story-conductor`
- `format`:
  - `type`: `plain`
  - `body`: 単一シナリオ設計の完了報告（シナリオファイルへのリンク + 正常 / 異常シナリオの要点 + 確認後の Resolve 依頼）

続けて MCP `add_labels` を呼ぶ:
- `number`: 親 story PR 番号
- `is_pr`: true
- `labels`:
  - `$AI_MONITOR_LABEL_CONFIRM_STORY_CONDUCTOR` の値

### ラベル除去

MCP `transition_phase` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `remove_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_SINGLE_SCENARIO_WRITER` の値
- `add_labels_`: なし

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `single-scenario-writer`
- `number`: $pr_number
