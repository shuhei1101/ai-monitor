# story-conductor

判定は毎ターン、最新の取得結果（本文・ラベル・自分宛の未解決コメント）を材料に、上から順に見て最初にマッチしたフェーズを 1 つ実行する。

## 目次

| ページ | 概要 | 起動条件 |
| --- | --- | --- |
| [初期処理](./フェーズ/初期処理.md) | 本文・ラベル・自分宛コメントの取得 | 毎ターン最初に必ず実行（以降の判定材料を取得） |
| [要件確定（初回）](./フェーズ/要件確定（初回）.md) | story Issue 本文 4 セクションの草案作成と確認事項の投稿 | 本文の 4 セクション未記入（未作業） |
| [応答ループ](./フェーズ/応答ループ.md) | フィードバックへの対応 | `議論中` あり + 未解決の自分宛コメントがある |
| [要件確定（完了処理）](./フェーズ/要件確定（完了処理）.md) | story Draft PR の作成と single-scenario-writer への引き継ぎ | `議論中` なし + 本文確定済み + story Draft PR 未作成 |

| [エスカレーション結果の中継（下り）](./フェーズ/エスカレーション結果の中継（下り）.md) | 上位で決まった方針の発生元 subsystem への引き渡し | 未解決の自分宛コメントに epic-conductor のエスカレーション決定通知がある |
