# エスカレーション対応（実行）

承認された方針で、発生元の subsystem へ決定を降ろすか、親 epic Issue へ中継する。

## 手順

### 選択された方針の確認

対応方針案コメントへのユーザー返信から、選ばれた案を確定する。

- story レベルの解決案が選ばれ、単一 UC シナリオの変更を伴う場合、「単一シナリオ修正の指示」へ進む
- story レベルの解決案が選ばれ、シナリオの変更を伴わない場合、「発生元 subsystem への決定通知」へ進む
- 上位への中継が選ばれた場合、「親 epic Issue への中継」へ進む（上記 2 つは実行しない）

story Issue 本文（`## ユースケース要件`）の変更を伴う決定だった場合、先に `update_body` で本文を更新する。

### 単一シナリオ修正の指示

MCP `comment` を呼ぶ:
- `number`: story PR の番号
- `is_pr`: true
- `sender`: `story-conductor`
- `receiver`: `single-scenario-writer`
- `format`:
  - `type`: `plain`
  - `body`: 決定した方針と、単一 UC シナリオのどこをどう直すか

続けて MCP `add_labels` を呼ぶ:
- `number`: story PR の番号
- `is_pr`: true
- `labels`:
  - `$AI_MONITOR_LABEL_CONFIRM_SINGLE_SCENARIO_WRITER` の値

発生元 subsystem への決定通知は、シナリオ修正の完了報告を受けてから「エスカレーション対応（決定通知）」で行う。
「中継コメントへの返信と Resolve」へ進む。

### 発生元 subsystem への決定通知

MCP `comment` を呼ぶ:
- `number`: 発生元の subsystem Issue 番号
- `is_pr`: false
- `sender`: `story-conductor`
- `receiver`: `subsystem-conductor`
- `format`:
  - `type`: `plain`
  - `body`: 決定した方針と、それを踏まえて再開してほしい作業

続けて MCP `add_labels` を呼ぶ:
- `number`: 発生元の subsystem Issue 番号
- `is_pr`: false
- `labels`:
  - `$AI_MONITOR_LABEL_CONFIRM_SUBSYSTEM_CONDUCTOR` の値

「中継コメントへの返信と Resolve」へ進む。

### 親 epic Issue への中継

MCP `comment` を呼ぶ:
- `number`: 親 epic Issue 番号
- `is_pr`: false
- `sender`: `story-conductor`
- `receiver`: `epic-conductor`
- `format`:
  - `type`: `plain`
  - `body`: 論点の要約 + story レベルで解決できない理由 + 元コメントへのリンク（発生元の subsystem Issue / PR 番号を含める）

続けて MCP `add_labels` を呼ぶ:
- `number`: 親 epic Issue 番号
- `is_pr`: false
- `labels`:
  - `$AI_MONITOR_LABEL_CONFIRM_EPIC_CONDUCTOR` の値

### 中継コメントへの返信と Resolve

MCP `reply_comment` を呼ぶ:
- `comment_node_id`: subsystem-conductor の中継コメントの node_id
- `sender`: `story-conductor`
- `receiver`: `subsystem-conductor`
- `format`:
  - `type`: `plain`
  - `body`: 決定内容（または親 epic へ中継した旨）

続けて MCP `resolve_comments` で自分宛コメントを一括 Resolve する。

### ラベル除去

MCP `transition_phase` を呼ぶ:
- `number`: $issue_number
- `is_pr`: false
- `remove_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_STORY_CONDUCTOR` の値
- `add_labels_`: なし

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `story-conductor`
- `number`: $issue_number
