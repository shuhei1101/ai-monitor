# バグ差し戻し（方針確認）

single-scenario-writer の失敗報告（実装側の問題）を受けて、対応方針案をユーザーに確認する。

## 手順

### 対応方針案の投稿

失敗内容から対応方針案を組み立てて投稿する。

MCP `comment` を呼ぶ:
- `number`: $number
- `is_pr`: true
- `sender`: `story-conductor`
- `receiver`: ユーザーログイン名
- `format`:
  - `type`: `plain`
  - `body`:
    ```
    単一 UC テストの失敗を受けた対応方針案です。

    | 修正対象 subsystem | 修正内容の要約 | 対応要否 |
    | --- | --- | --- |
    | #{番号} {subsystem 名} | {要約} | {要 / 不要} |

    - 問題なければ `議論中` ラベルを外す → 該当 subsystem へ差し戻します
    - 調整が必要なら assignee を外してフィードバックコメントを記入
    ```

### 議論中 付与 + 待機

MCP `add_labels` を呼ぶ:
- `number`: $number
- `is_pr`: true
- `labels`:
  - `$AI_MONITOR_LABEL_IN_DISCUSSION` の値

続けて MCP `set_assignee` を呼ぶ:
- `number`: $number
- `is_pr`: true

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `story-conductor`
- `number`: $number
