# 統合テスト起動

subsystem-conductor の完了報告を受けて、全子 subsystem の close 状態に応じて統合テストを single-scenario-writer に委任する（未完了があれば状況確認）。

## 手順

### 全子 subsystem の確認

初期処理で取得した Sub-issue の state を確認する。

### 完了報告の Resolve と分岐

MCP `resolve_comments` で subsystem-conductor の完了報告コメントを Resolve する。

- 全子 subsystem が closed の場合、「統合テストの成果物 PR の用意」へ進む
- open の subsystem が残っている場合、open の各 subsystem PR に状況確認を送り、「作業完了報告」まで飛ばす（「統合テストの成果物 PR の用意」「single-scenario-writer への委任」は実行しない）:
  1. MCP `comment` を呼ぶ（`number`: open の subsystem PR 番号・`is_pr`: true・`sender`: `story-conductor`・`receiver`: `subsystem-conductor`・`format`: `type` が `plain` で `body` が 進捗とブロッカーの確認）
  2. MCP `add_labels` を呼ぶ（`number`: open の subsystem PR 番号・`is_pr`: true・`labels`: `$AI_MONITOR_LABEL_CONFIRM_SUBSYSTEM_CONDUCTOR` の値）

### 統合テストの成果物 PR の用意

統合テストは story ブランチ直下の成果物ブランチで行う（規約『ブランチ戦略』の成果物ブランチ）。

- 成果物 PR が既に open の場合（バグ修正後の再テスト）は作り直さず、その PR を委任先にして「single-scenario-writer への委任」へ進む

自分の story ブランチ名 `{type}/story/{ドメイン}/{UC名}/base` からドメイン部と UC 名を取り出して成果物ブランチを組み立てる。

MCP `worktree_create` を呼ぶ:
- `branch`: `test/story/{ドメイン}/{UC名}/integration`
- `base_ref`: `origin/{自分の story ブランチ}`

続けて MCP `create_draft_pr` を呼ぶ:
- `head_branch`: 作成したブランチ
- `base_branch`: 自分の story ブランチ
- `title`: `{story のタイトル}（単一ユースケース統合テスト）`
- `body`: `## 紐づく Issue`（story PR と同じ起点の Issue 番号）と `## タスク一覧`
- `labels`: `$AI_MONITOR_LABEL_TYPE_TEST` の値

`## タスク一覧` は E2E テストコードの作成とテストの実行を行に分けて列挙する（書式はテンプレート「PR本文/統合テスト」）。
チェックは各行を担当した作業者が入れるので、ここでは全行を未チェックで作る。

続けて MCP `add_watch_targets` を呼ぶ:
- `agent_name`: `story-conductor`
- `number`: $number
- `watch_numbers`: 作成した PR の番号

### single-scenario-writer への委任

MCP `comment` を呼ぶ:
- `number`: 統合テストの成果物 PR の番号
- `is_pr`: true
- `sender`: `story-conductor`
- `receiver`: `single-scenario-writer`
- `format`:
  - `type`: `plain`
  - `body`: 委任の経緯（初回実装か、バグ修正後の再テストか）

続けて MCP `add_labels` を呼ぶ:
- `number`: 統合テストの成果物 PR の番号
- `is_pr`: true
- `labels`:
  - `$AI_MONITOR_LABEL_CONFIRM_SINGLE_SCENARIO_WRITER` の値

初回実装か再テストかの判定は writer がテスト結果表で行う。

### ラベル除去

MCP `transition_phase` を呼ぶ:
- `number`: $number
- `is_pr`: true
- `remove_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_STORY_CONDUCTOR` の値
- `add_labels_`: なし

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `story-conductor`
- `number`: $number
