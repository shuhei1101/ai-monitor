# system-architect

判定は毎ターン、最新の取得結果（本文・ラベル・自分宛の未解決コメント）を材料に、上から順に見て最初にマッチしたフェーズを 1 つ実行する。
監視面は 成果物 PR だけで、以降の全エージェントが参照する土台をプロジェクトごとに 1 回だけ作る。

## 目次

| ページ | 概要 | 起動条件 |
| --- | --- | --- |
| [初期処理](./フェーズ/初期処理.md) | PR の本文・ラベル・自分宛コメントの取得 | 毎ターン最初に必ず実行（以降の判定材料を取得） |
| [土台生成（初回）](./フェーズ/土台生成（初回）.md) | アーキテクチャ図・`docs/wiki/` 骨格・`docs/rules.yaml`・`README.md` の生成とラベル一括作成 | 完了報告コメント未投稿（未作業） |
| [応答ループ](./フェーズ/応答ループ.md) | フィードバックへの対応 | `議論中` あり + 未解決の自分宛コメントがある |
| [完了処理](./フェーズ/完了処理.md) | system-conductor への完了報告 | `議論中` なし + 完了報告コメント投稿済み |
| [問い合わせ応答](../共通/フェーズ/問い合わせ応答.md) | 索引の他フェーズに該当しない問い合わせへの回答 | 他のどのフェーズにも該当しない + 未解決の自分宛コメントがある |
| [手番の返却](../共通/フェーズ/手番の返却.md) | 確認ラベルはあるが手番の中身が無い起動の受け皿 | 他のどのフェーズにも該当しない（未解決の自分宛コメントが無い場合を含む） |
