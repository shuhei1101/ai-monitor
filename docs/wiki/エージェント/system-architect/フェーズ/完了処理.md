# 完了処理

ユーザー承認を受けて自分宛コメントを Resolve し、system-conductor へ土台生成の完了を報告する。

## 手順

### 自分宛コメントの選別

未回答・未対応の自分宛コメントが残る場合は「応答ループ」に戻ってユーザーに確認質問を投げる（以降の手順は実行しない）。

未解決のインライン確認事項スレッドが残っている場合も同じ扱いにする（応答ループの「決着したスレッドの Resolve」で畳めなかったものが該当する）。
決めきれていない論点を残したまま次工程へ渡さない。
- 回答なしで `議論中` を外されたのが 2 回目以降の場合は、推奨案への承認とみなして応答ループへ戻さず先へ進む（共通ルール『議論中ラベル』の「回答なしで外されたとき」）

### 一括 Resolve

MCP `resolve_comments` を呼ぶ:
- `node_ids`: 成果物 PR の自分宛コメントの `node_id` 配列

### 最終確認

成果物ブランチの worktree へ移動し、`git pull --ff-only` でリモートの最新を取り込む。
`## タスク一覧` が全てチェック済みであることと、生成物が最新の確定版であることを確認する。

### system-conductor への完了報告

MCP `comment` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `sender`: `system-architect`
- `receiver`: `system-conductor`
- `format`:
  - `type`: `commits`
  - `body`: 土台生成の完了報告（生成したページ一覧 + 作成したラベル + ユーザー承認済みである旨）
  - `entries`: 積んだ commit の `commit` と `summary` の組

MCP `transition_phase` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `remove_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_SYSTEM_ARCHITECT` の値
- `add_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_SYSTEM_CONDUCTOR` の値

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `system-architect`
- `number`: $pr_number
