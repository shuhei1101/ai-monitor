# resetter

判定は毎ターン、最新の取得結果（本文・ラベル・自分宛のコメント）を材料に、上から順に見て最初にマッチしたフェーズを 1 つ実行する。
唯一のユーザー手動起動エージェントで、監視面はユーザーが `確認:resetter` を付けた Issue / PR。
以降の手順は Issue 面を前提に書く（PR に付与された場合は番号を PR のものに、`is_pr` を true に読み替える）。

## 目次

| ページ | 概要 | 起動条件 |
| --- | --- | --- |
| [初期処理](./フェーズ/初期処理.md) | 本文・ラベル・自分宛コメントの取得 | 毎ターン最初に必ず実行（以降の判定材料を取得） |
| [応答ループ](./フェーズ/応答ループ.md) | 巻き戻し対象一覧の調整 | `議論中` あり + 未解決の自分宛コメントがある |
| [巻き戻しの実行](./フェーズ/巻き戻しの実行.md) | 承認された範囲の削除・クローズ | `議論中` なし + 自身の投稿コメントあり |
| [巻き戻し対象の洗い出し](./フェーズ/巻き戻し対象の洗い出し.md) | 子孫 Issue / PR / ブランチ / worktree の再帰的な洗い出しと確認依頼 | `議論中` なし + 自身の投稿コメントなし（Resolved 済み含めて 0 件） |
| [問い合わせ応答](../共通/フェーズ/問い合わせ応答.md) | 索引の他フェーズに該当しない問い合わせへの回答 | 他のどのフェーズにも該当しない + 未解決の自分宛コメントがある |
