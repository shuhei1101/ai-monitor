# 応答ループ

待機中のユーザーの調整指示に対応し、巻き戻し対象一覧を更新して再び待機に入る。

## 手順

### 内容に応じた対応

| 待機の文脈 | 対応 |
| --- | --- |
| 「これは残す」の指示 | 対象一覧から該当行を外し、更新後の一覧を追記 |
| 「別 Issue へ移譲する」の指示 | 移譲先を対象一覧の補足に書き、削除対象からは外して更新後の一覧を追記 |
| 対象範囲への質問 | 洗い出しの根拠（どの親子リンク・どの PR から辿ったか）を追記 |
| 上記以外 | 文脈から必要な対応を判断して実施し、対応内容を短く追記 |

一覧はコメントが最新の確定版になるように、更新後の全体を追記する。

追記は MCP `reply_comment` を呼ぶ:
- `comment_node_id`: 巻き戻し対象一覧コメントの node_id
- `sender`: `resetter`
- `receiver`: ユーザーログイン名（`gh api user --jq '.login'` で取得）
- `format`:
  - `type`: `plain`
  - `body`: 更新後の一覧と変更点

### assignee 再設定

MCP `set_assignee` を呼ぶ:
- `number`: $issue_number
- `is_pr`: false

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `resetter`
- `number`: $issue_number
