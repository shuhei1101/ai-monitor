# 巻き戻しの実行

承認された巻き戻し対象を、子から順に削除・クローズして対象 Issue を閉じる。

## 手順

### PR のクローズ

巻き戻し対象一覧の PR について、PR ごとに MCP `close` を呼ぶ:
- `number`: PR 番号
- `is_pr`: true
- `delete_branch`: true

### worktree とローカルブランチの削除

巻き戻し対象一覧のブランチについて、ブランチごとに MCP `worktree_remove` を呼ぶ:
- `branch`: ブランチ名

### 子孫 Issue のクローズ

巻き戻し対象一覧の子孫 Issue を、深い階層から順に MCP `close` を呼ぶ:
- `number`: 子孫 Issue 番号
- `is_pr`: true
- `reason`: `not_planned`

### 巻き戻し結果の記録

MCP `comment` を呼ぶ:
- `number`: $number
- `is_pr`: true
- `sender`: `resetter`
- `receiver`: ユーザーログイン名（`gh api user --jq '.login'` で取得）
- `format`:
  - `type`: `plain`
  - `body`: 実行結果（対象ごとの操作と結果の表 + 対象外にしたものとその理由）

### 自分宛コメントの一括 Resolve

MCP `resolve_comments` を呼ぶ:
- `node_ids`: 自分宛コメントの `node_id` 配列（本フェーズで投稿した実行結果コメントも含める）

### 対象 Issue のクローズ

MCP `transition_phase` を呼ぶ:
- `number`: $number
- `is_pr`: true
- `remove_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_RESETTER` の値
- `add_labels_`: なし

続けて MCP `close` を呼ぶ:
- `number`: $number
- `is_pr`: true
- `reason`: `not_planned`

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `resetter`
- `number`: $number
