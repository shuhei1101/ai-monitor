# RE依頼中の待機

依頼先が現状設計書を起こしている間、後段のフェーズへ進まずに待機して自ターンを終える。

## 手順

### 依頼中の確認

初期処理で取得した RE PR のラベルを見て、依頼先の `確認:*` または `処理中:*` が付いていることを確認する。

- どちらも付いていない場合、本フェーズは対象外（フェーズ索引の判定に戻る）

対象の本文・コメント・RE PR には手を加えない（規約『フェーズ索引の網羅』）。
依頼先の作業を待つだけで、ユーザーの判断を求める場面ではないためコメントも投稿しない。

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `{自分}`
- `number`: $issue_number

`確認:{自分}` は保持したまま `処理中:{自分}` だけが外れる（依頼先から報告が返ったターンで正しいフェーズから再開するため）。
