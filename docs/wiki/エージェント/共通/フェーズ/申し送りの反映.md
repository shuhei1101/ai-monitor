# 申し送りの反映

下位レイヤーの conductor から届いた「自レイヤーの本文へ反映してほしい」という申し送りを、自 PR の本文へ反映する。

## 手順

### 申し送り内容の確認

未解決の自分宛コメントから、反映してほしい内容と決着の経緯を読む。

- ユーザーの判断が要る内容（下位で決着しておらず、自レイヤーで判断が割れる）の場合、「エスカレーション対応（方針確認）」へ進む（以降の手順は実行しない）
- 自レイヤーの本文で表せない内容（さらに上位の要件に関わる）の場合、「エスカレーション対応（方針確認）」で上位中継を選択肢に載せる（同上）

### 本文への反映

MCP `update_body` を呼ぶ:
- `number`: $number
- `is_pr`: true
- `body`: 申し送りを反映した本文（変更するのは該当セクションだけ。共通ルール『既存文章の維持』）

### 申し送り元への返信と Resolve

MCP `reply_comment` を呼ぶ:
- `comment_node_id`: 申し送りコメントの node_id
- `sender`: `{自分}`
- `receiver`: 申し送り元
- `format`:
  - `type`: `plain`
  - `body`: 反映した内容と反映先のセクション名

続けて MCP `resolve_comments` を呼ぶ:
- `node_ids`: 申し送りコメントの `node_id`

### ラベル除去

MCP `transition_phase` を呼ぶ:
- `number`: $number
- `is_pr`: true
- `remove_labels_`:
  - 自分の確認ラベル（`AI_MONITOR_LABEL_CONFIRM_*`）の値
- `add_labels_`: なし

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `{自分}`
- `number`: $number
