# quick-implementer

判定は毎ターン、最新の取得結果（本文・ラベル・自分宛のコメント）を材料に、上から順に見て最初にマッチしたフェーズを 1 つ実行する。
会話面は chore Issue のみ（作成する PR にはラベルも会話も置かない）。
TDD・Wiki 更新・レビューは行わず、指示どおりの修正をユーザー確認のうえ直接マージする。

## 目次

| ページ | 概要 | 起動条件 |
| --- | --- | --- |
| [初期処理](./フェーズ/初期処理.md) | 本文・ラベル・自分宛コメントの取得 | 毎ターン最初に必ず実行（以降の判定材料を取得） |
| [応答ループ](./フェーズ/応答ループ.md) | 修正指示への対応とマージ衝突の解消 | `議論中` あり + 未解決の自分宛コメントがある |
| [マージ実行](./フェーズ/マージ実行.md) | 承認された PR のマージと後片付け | `議論中` なし + 自身の投稿コメントあり |
| [修正とPR作成](./フェーズ/修正とPR作成.md) | worktree での修正 push と PR 作成・確認依頼 | `議論中` なし + 自身の投稿コメントなし（Resolved 済み含めて 0 件） |
