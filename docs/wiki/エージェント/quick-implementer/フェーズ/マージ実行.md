# マージ実行

承認された PR を master へマージし、worktree と chore Issue を片付ける。

## 手順

### PR のマージ

MCP `merge_pr` を呼ぶ:
- `pr_number`: 作成した PR 番号（初期処理で取得した監視面、または確認依頼コメントのリンクから特定する）
- `strategy`: `squash`

- マージが衝突で失敗した場合、「衝突の相談 + 待機」を実行して自ターンを終える（以降の手順は実行しない）

### 自分宛コメントの一括 Resolve

MCP `resolve_comments` を呼ぶ:
- `node_ids`: 自分宛コメントの `node_id` 配列

### worktree の削除

MCP `worktree_remove` を呼ぶ:
- `branch`: マージしたブランチ

### 監視面の除去

MCP `remove_watch_targets` を呼ぶ:
- `agent_name`: `quick-implementer`
- `number`: $issue_number
- `watch_numbers`: マージした PR 番号

### chore Issue のクローズ

MCP `transition_phase` を呼ぶ:
- `number`: $issue_number
- `is_pr`: false
- `remove_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_QUICK_IMPLEMENTER` の値
- `add_labels_`: なし

続けて MCP `close` を呼ぶ:
- `number`: $issue_number
- `is_pr`: false
- `reason`: `completed`

「作業完了報告」へ進む。

### 衝突の相談 + 待機

MCP `comment` を呼ぶ:
- `number`: $issue_number
- `is_pr`: false
- `sender`: `quick-implementer`
- `receiver`: ユーザーログイン名（`gh api user --jq '.login'` で取得）
- `format`:
  - `type`: `plain`
  - `body`: 衝突の内容（衝突したファイルと双方の変更）と解消案

続けて MCP `add_labels` を呼ぶ:
- `number`: $issue_number
- `is_pr`: false
- `labels`:
  - `$AI_MONITOR_LABEL_IN_DISCUSSION` の値

続けて MCP `set_assignee` を呼ぶ:
- `number`: $issue_number
- `is_pr`: false

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `quick-implementer`
- `number`: $issue_number
