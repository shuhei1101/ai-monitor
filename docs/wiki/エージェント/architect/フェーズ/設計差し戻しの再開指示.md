# 設計差し戻しの再開指示

ユーザーが承認した設計修正をもって、差し戻し元の worker に工程の再開を指示する。

## 手順

### 再開指示の返信

MCP `reply_comment` を呼ぶ:
- `comment_node_id`: 差し戻し報告コメントの node_id
- `sender`: `architect`
- `receiver`: 差し戻し元の worker 名（`tester` or `implementer`）
- `body`: 修正 commit の ID を参照した再開指示（スレッドは Resolve しない = 差し戻し元 worker が処理時に Resolve する）

### ラベル遷移

MCP `transition_phase` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `remove_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_ARCHITECT` の値
- `add_labels_`:
  - 差し戻し元が tester なら `$AI_MONITOR_LABEL_CONFIRM_TESTER`、implementer なら `$AI_MONITOR_LABEL_CONFIRM_IMPLEMENTER` の値

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `architect`
- `number`: $pr_number
