# ライブラリ採用の反映

ユーザーが決定した採用ライブラリを外部ライブラリ Wiki に反映し、内容の確認を依頼して待機する。

## 手順

### 外部ライブラリ Wiki の作成

subsystem ブランチの worktree で `外部ライブラリ/{lib名}.md` を作成 / 更新し、`外部ライブラリ/README.md` の一覧に行を追加して commit push する。
記入内容は PoC PR 本文の `## 検証対象` / `## 調査結果`（PoC を実施していない場合は library-researcher の調査結果）から転記する。

### 反映報告の投稿 + 待機

MCP `comment` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `sender`: `architect`
- `receiver`: ユーザーログイン名（`gh api user --jq '.login'` で取得）
- `body`: Wiki 反映の報告（作成 / 更新したページ名 + 記載内容の要約 + 承認・修正方法の案内）

続けて MCP `add_labels` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `labels`:
  - `$AI_MONITOR_LABEL_IN_DISCUSSION` の値

続けて MCP `set_assignee` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `architect`
- `number`: $pr_number
