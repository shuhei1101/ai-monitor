# 実装レビュー

worktree でテストを再実行して Green を実測確認し、diff を自分が確定させた設計 Wiki と照合したうえで subsystem-conductor に一式完了を報告する。
ユーザーとのやり取りはせず、指摘は implementer に直接差し戻す。

## 手順

### テストの再実行

subsystem ブランチの worktree を最新化し、`## 単体テスト結果` / `## 結合テスト結果` / `## 単一ユースケースシナリオテスト結果` / `## 複合ユースケースシナリオテスト結果` に載っているテストを再実行して Green を実測する。

### diff のレビュー

完了報告のコミット表から見る範囲を決め、差分を取得する（共通ルール『PR差分の取得』）。
取得した差分を設計 Wiki（ER図 / 画面構成 / 結合 / モジュール構成）と照合し、バグ・可読性・保守性を見る

- テストが Green にならない場合、または diff に指摘がある場合、「インライン指摘の投稿」へ進む
- Green かつ指摘がない場合、「レビュー結果の返信と Resolve」へ進む（「インライン指摘の投稿」は実行しない）

### インライン指摘の投稿

指摘 1 件ごとに MCP `create_review_comment` を呼ぶ:
- `pr_number`: $pr_number
- `path`: 指摘対象のファイルパス
- `line`: 指摘対象の行
- `sender`: `architect`
- `receiver`: `implementer`
- `body`: 設計 Wiki との差異・バグ・可読性の問題と期待する修正

続けて MCP `reply_comment` を呼ぶ:
- `comment_node_id`: implementer の完了報告コメントの node_id
- `sender`: `architect`
- `receiver`: `implementer`
- `body`: インライン指摘への対応依頼（テスト再実行の実測結果 + 指摘の件数と要点。スレッドは Resolve しない）

続けて MCP `transition_phase` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `remove_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_ARCHITECT` の値
- `add_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_IMPLEMENTER` の値

「作業完了報告」を実行して自ターンを終える（以降の手順は実行しない）。

### レビュー結果の返信と Resolve

MCP `reply_comment` を呼ぶ:
- `comment_node_id`: implementer の完了報告コメントの node_id
- `sender`: `architect`
- `receiver`: `implementer`
- `body`: レビュー結果（テスト再実行の実測結果 + 指摘なし）

続けて MCP `resolve_comments` を呼ぶ:
- `node_ids`: implementer の完了報告コメントの `node_id`

### インライン指摘スレッドの解決

MCP `list_review_threads` を呼ぶ:
- `pr_number`: $pr_number
- `include_resolved`: false

続けて MCP `resolve_review_threads` を呼ぶ:
- `thread_node_ids`: 取得したスレッドの `node_id` 配列

### タスク一覧のチェック

subsystem PR 本文の `## タスク一覧` の実装・テスト実行タスクを `[x]` にする（本手順で全行がチェック済みになる）。

MCP `update_body` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `body`: 更新後本文

### subsystem-conductor への一式完了報告

MCP `comment` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `sender`: `architect`
- `receiver`: `subsystem-conductor`
- `body`: 一式完了報告（設計 → テスト → 実装 → レビューの結果要約 + テスト実測結果）

続けて MCP `add_labels` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `labels`:
  - `$AI_MONITOR_LABEL_CONFIRM_SUBSYSTEM_CONDUCTOR` の値

### ラベル除去

MCP `transition_phase` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `remove_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_ARCHITECT` の値
- `add_labels_`: なし

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `architect`
- `number`: $pr_number
