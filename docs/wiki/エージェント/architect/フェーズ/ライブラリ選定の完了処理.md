# ライブラリ選定の完了処理

外部ライブラリ Wiki が承認されたので、ライブラリ選定の自分宛コメントを Resolve し、PoC の成果物を片付けて設計の応答ループに戻る。

## 手順

### ライブラリ選定関連の一括 Resolve

MCP `resolve_comments` を呼ぶ:
- `node_ids`: 候補比較・結果まとめ・Wiki 反映報告の各コメントの `node_id` 配列（設計提案コメントは対象外 = ページの確定は「テスト作成の委任」で行う）

### PoC PR の close

PoC を実施していない場合は本手順と「監視面の除去」「PoC worktree の削除」を飛ばして「待機」へ進む。

PoC PR ごとに MCP `close` を呼ぶ:
- `number`: PoC PR の番号
- `is_pr`: true
- `reason`: `completed`
- `delete_branch`: true

### 監視面の除去

MCP `remove_watch_targets` を呼ぶ:
- `agent_name`: `architect`
- `number`: $pr_number
- `watch_numbers`: close した全 PoC PR の番号

### PoC worktree の削除

PoC ブランチごとに MCP `worktree_remove` を呼ぶ:
- `branch`: PoC ブランチ名

### 待機

MCP `set_assignee` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true

`議論中` と `確認:architect` は保持したまま設計の応答ループに戻る。

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `architect`
- `number`: $pr_number
