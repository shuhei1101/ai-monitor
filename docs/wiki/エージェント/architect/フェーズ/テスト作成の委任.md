# テスト作成の委任

担当分の設計 Wiki が全て確定したので、設計タスクにチェックを入れて tester にテスト作成を割り当てる。

## 手順

### 自分宛コメントの選別

未回答・未対応の自分宛コメントが残る場合は「応答ループ」に戻ってユーザーに確認質問を投げる（以降の手順は実行しない）。

### 一括 Resolve

MCP `resolve_comments` を呼ぶ:
- `node_ids`: subsystem PR の自分宛コメントの `node_id` 配列

### タスク一覧のチェック

subsystem PR 本文の `## タスク一覧` の設計タスクを `[x]` にする。

MCP `update_body` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `body`: 更新後本文

### tester へのテスト作成の割り当て

MCP `comment` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `sender`: `architect`
- `receiver`: `tester`
- `format`:
  - `type`: `pages`
  - `body`: テスト作成の指示（テスト観点の起点になる結合 / モジュール構成のページ名）
  - `entries`: 各ページの `page` と `commit`（範囲があれば `start_commit` も）の組

### ラベル遷移

MCP `transition_phase` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `remove_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_ARCHITECT` の値
- `add_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_TESTER` の値

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `architect`
- `number`: $pr_number
