# architect

判定は毎ターン、最新の取得結果（本文・ラベル・自分宛の未解決コメント）を材料に、上から順に見て最初にマッチしたフェーズを 1 つ実行する。
監視面は subsystem PR（設計・レビュー・配下 worker との往復）と、ライブラリ選定で発注した PoC PR（library-poc-runner との往復）の 2 つで、起動条件の「本文」「ラベル」はフェーズごとに対象の面のものを見る。

## 目次

| [SS設計（初回）](./フェーズ/SS設計（初回）.md) | SA の確認・領域別アーキ調査と担当分の全設計ページの提案 | subsystem PR に自分の設計提案コメントが未投稿（未作業）+ `## タスク一覧` に設計タスクがある |
