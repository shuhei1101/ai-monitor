# シナリオ修正の再開指示

ユーザーが承認したシナリオ修正をもって、complex-scenario-tester にテストコードの修正を指示する。

## 手順

### 再開指示の返信

MCP `reply_comment` を呼ぶ:
- `comment_node_id`: complex-scenario-tester のテスト実装完了報告コメントの node_id
- `sender`: `complex-scenario-writer`
- `receiver`: `complex-scenario-tester`
- `format`:
  - `type`: `plain`
  - `body`: 修正 commit の ID を参照した、テストコードの修正の再開指示（スレッドは Resolve しない = tester が処理時に Resolve する）

### ラベル遷移

MCP `transition_phase` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `remove_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_COMPLEX_SCENARIO_WRITER` の値
- `add_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_COMPLEX_SCENARIO_TESTER` の値

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `complex-scenario-writer`
- `number`: $pr_number
