# 再テストの実行指示

バグ修正後に再委任された統合テストについて、レビュー済みのテストをそのまま再実行するよう complex-scenario-tester に指示する。

## 手順

### 再テストであることの確認

epic PR 本文の `## 複合ユースケースシナリオテスト結果` に `❌` の記録が残っていることを確認する。
テストは実装・レビュー済みなので、実装フェーズは経由しない。

### 実行指示の投稿

MCP `comment` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `sender`: `complex-scenario-writer`
- `receiver`: `complex-scenario-tester`
- `body`: 実行指示（バグ修正が入ったのでテスト結果表の全行を再実行して結果列を更新する旨）

続けて MCP `transition_phase` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `remove_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_COMPLEX_SCENARIO_WRITER` の値
- `add_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_COMPLEX_SCENARIO_TESTER` の値

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `complex-scenario-writer`
- `number`: $pr_number
