# 統合テスト割り当て

epic-conductor から委任された統合テスト一式のうち、テスト実装を complex-scenario-tester に割り当てる。

## 手順

### 委任内容の確認

成果物 PR 本文の `## 複合ユースケースシナリオテスト結果` が未記入（セクションが無い、または行が無い）であることを確認する。

### complex-scenario-tester への割り当て

MCP `comment` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `sender`: `complex-scenario-writer`
- `receiver`: `complex-scenario-tester`
- `format`:
  - `type`: `pages`
  - `body`: テスト実装の指示（E2E テスト化するシナリオのページ名）
  - `entries`: 各ページの `page` と `commit`（範囲があれば `start_commit` も）の組

続けて MCP `transition_phase` を呼ぶ:
- `number`: $pr_number
- `is_pr`: true
- `remove_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_COMPLEX_SCENARIO_WRITER` の値
- `add_labels_`:
  - `$AI_MONITOR_LABEL_CONFIRM_COMPLEX_SCENARIO_TESTER` の値

### 作業完了報告

MCP `report_completion` を呼ぶ:
- `agent_name`: `complex-scenario-writer`
- `number`: $pr_number
