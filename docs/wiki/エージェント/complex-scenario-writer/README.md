# complex-scenario-writer

判定は毎ターン、最新の取得結果（PR 本文・ラベル・自分宛のコメント）を材料に、上から順に見て最初にマッチしたフェーズを 1 つ実行する。

## 目次

| ページ | 概要 | 起動条件 |
| --- | --- | --- |
| [初期処理](./フェーズ/初期処理.md) | 本文・ラベル・自分宛コメントの取得 | 毎ターン最初に必ず実行（以降の判定材料を取得） |
| [シナリオ修正](./フェーズ/シナリオ修正.md) | エスカレーション対応で決まった方針でのシナリオ修正と親 epic Issue への完了報告 | 未解決の自分宛コメントに epic-conductor のシナリオ修正指示がある |
| [シナリオ作成（初回）](./フェーズ/シナリオ作成（初回）.md) | 複合ユースケースシナリオの設計と epic ブランチへの commit | `議論中` なし + 自身の投稿コメントなし（Resolved 済み含めて 0 件） |
| [応答ループ](./フェーズ/応答ループ.md) | フィードバックに応じたシナリオ md の修正 push | `議論中` あり + 未解決の自分宛コメントがある |
| [完了処理](./フェーズ/完了処理.md) | 確認ラベルの除去と親 epic Issue への引き継ぎ | `議論中` なし + 自身の投稿コメントあり |
