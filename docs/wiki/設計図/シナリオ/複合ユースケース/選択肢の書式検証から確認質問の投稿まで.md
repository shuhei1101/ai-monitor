# 選択肢の書式検証から確認質問の投稿まで

エージェントが確認質問を複数まとめて投げたとき、選択肢ラベルの書式検証を通った質問だけが 1 質問 = 1 コメントとして投稿され、ユーザーが質問ごとに回答できる状態になるまでの複合ユースケース。

**E2E テストの位置付け:** 書式検証と個別投稿は 1 回の呼び出しの中で連鎖するため、検証が投稿を止められるか（書式違反が 1 件でもあれば 1 コメントも残らないか）は 2 UC をまたいで初めて観測できる。
確認するのは 2 UC のつなぎ目までで、コメント本文の組み立て内容そのものは結合ドキュメント側で見る。

- 対応テストファイル: `tests/e2e/複合ユースケース/test_選択肢の書式検証から確認質問の投稿まで.py`

## 正常シナリオ

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | なし（実環境で実行） | - |
| sandbox リポ存在 | `shuhei1101/ai-monitor-e2e` が存在 | - |
| 対象 Issue | sandbox に open の Issue が 1 件存在 | コメント 0 件の状態から始める |
| 呼び出し内容 | 確認質問 3 件を 1 回の呼び出しで投げる | 分割を観測できる最小件数 |
| 選択肢ラベル | 全質問のラベル先頭に採番記号を含まない | 検証通過を決定的に誘発 |
| 宛先 | 受信者にユーザーのログイン名を指定 | to 行の付与を観測するため |

### フロー

```mermaid
flowchart TD
  A0([確認質問を投げるエージェント]) -->|対象 Issue への確認質問 3 件を<br>1 回の呼び出しで投稿依頼| UC1

  subgraph FOCUS["検証対象: 書式検証の通過 → 質問ごとの個別投稿"]
    UC1([選択肢ラベルの書式検証:正常シナリオ]) -->|検証を通った質問 3 件| UC2([確認質問の個別投稿:正常シナリオ])
  end

  UC2 -->|質問ごとに独立したコメントを投稿| DONE([質問 3 件が 3 コメントに分かれ<br>ユーザーが質問ごとに回答できる状態])

  click UC1 "../単一ユースケース/選択肢ラベルの書式検証.md#正常シナリオ"
  click UC2 "../単一ユースケース/確認質問の個別投稿.md#正常シナリオ"
```

### 期待値

- 対象 Issue のコメントが質問件数と同じ 3 件増えている
- 各コメントが質問 1 件だけを含み、質問文・背景・選択肢・推奨が揃っている
- 各コメントの先頭に引用ヘッダー（送信者の from 行 + 受信者の to 行）が付いている
- 各コメントの選択肢行に採番記号が 1 つだけ付いている
- 各コメントが区切り線と空行で終わっている（ユーザーがそのまま回答を書き足せる状態）
- 各コメントの冒頭に同じ前置き文が繰り返されている

## 異常シナリオ（選択肢ラベルの先頭に採番記号を含む）

### セットアップ

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| Mock | なし（実環境で実行） | - |
| sandbox リポ存在 | `shuhei1101/ai-monitor-e2e` が存在 | - |
| 対象 Issue | sandbox に open の Issue が 1 件存在 | コメント 0 件の状態から始める |
| 呼び出し内容 | 確認質問 3 件を 1 回の呼び出しで投げる | - |
| 選択肢ラベル | 3 件目の質問のラベル先頭にだけ採番記号を含める | 検証エラーを決定的に誘発 |

### フロー

```mermaid
flowchart TD
  A0([確認質問を投げるエージェント]) -->|対象 Issue への確認質問 3 件を<br>1 回の呼び出しで投稿依頼<br>（3 件目のラベル先頭に採番記号）| UC1

  UC1([選択肢ラベルの書式検証:異常シナリオ<br>（ラベル先頭に採番記号）]) -->|違反を検出してエラーを返し<br>個別投稿へ渡さない| E1([コメントが 1 件も<br>投稿されていない状態])

  click UC1 "../単一ユースケース/選択肢ラベルの書式検証.md#異常シナリオラベル先頭に採番記号"
```

### 期待値

- 呼び出し側にエラーが返り、違反した質問と選択肢を特定できる内容を含んでいる
- 対象 Issue のコメントが 1 件も増えていない（違反しなかった 2 件分も投稿されていない）
