# バックエンド結合

ai-monitor 自身のバックエンド 1 操作（MCP ツール / 注入 CLI）ごとの処理フロー集。
1 ファイル = 1 操作 = 結合テスト 1 ファイル。
エージェントの GitHub 操作もモニターへの連絡も本 MCP 経由に限定する（`議論中` の除去エンドポイントは提供しない = 外せるのはユーザーのみ）。
