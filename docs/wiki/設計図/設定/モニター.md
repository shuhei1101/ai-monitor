# 設定: モニター

`モニター` の設定値一覧。

- 置き場所は `~/.config/ai-monitor/settings.yaml`（`settings.yaml.example` をコピーして作成。MCP と共用）
- 環境差分は `settings.{環境}.yaml` に書き、環境名は環境変数 `AI_MONITOR_ENV`（または起動引数 `--env`）で指定する
- 実装は `shared/settings.py`（pydantic-settings）を参照
- ラベル定数の SoT は `plugins/ai-monitor/constants.env`

## ファイル一覧

| ファイル | 管理する値 | 補足 |
| --- | --- | --- |
| `~/.config/ai-monitor/settings.yaml` | 共通の設定値（秘匿情報含む） | git 管理外。サンプルは `settings.yaml.example` |
| `~/.config/ai-monitor/settings.e2e.yaml` | 外部疎通テスト・sandbox E2E 用の差分 | `AI_MONITOR_ENV=e2e` で読み込み |
| `config/agent_phases.yaml` | エージェント別のフェーズページ一覧 | git 管理。ai-monitor のメインリポジトリ直下 |

## settings.yaml

| 論理名 | キー | 型 | 必須 | 既定値 | 説明 | 補足 |
| --- | --- | --- | --- | --- | --- | --- |
| GitHub Token | `github_token` | `str` | ✅ | - | GitHub API（githubkit）の認証 PAT | 秘匿。欠落時は起動エラー。fine-grained PAT に監視対象全リポジトリの Issues / PR / Contents の RW を付与 |
| 待受ポート | `port` | `int` | - | `8765` | モニターの待受ポート | bind 先は `127.0.0.1` 固定。エージェントは `/mcp` へ接続する |
| ポーリング間隔 | `poll_interval_sec` | `int` | - | `15` | GitHub ポーリングの周期（秒） | - |
| セッションタイムアウト | `session_timeout_min` | `int` | - | `30` | 処理中のまま超過したセッションを kill する閾値（分） | 待機中（assignee=ユーザー）は対象外 |
| heartbeat 間隔 | `heartbeat_interval_sec` | `int` | - | `60` | 生存確認の周期（秒） | 確認に失敗した（tmux にセッションが無い）場合は台帳から除去して tmux 側の実態に合わせる |
| 状態ファイル | `state_path` | `str` | - | `data/state.yaml` | セッション台帳の永続化先 | - |
| 監視対象プロジェクト | `projects[]` | `list` | ✅ | - | 監視するプロジェクトの一覧 | 子キーは下の行で展開 |
| 監視対象プロジェクト | `projects[].name` | `str` | ✅ | - | tmux セッション名・台帳キーに使う名前 | - |
| 監視対象プロジェクト | `projects[].repo` | `str` | ✅ | - | GitHub リポジトリ（`owner/name`） | - |
| 監視対象プロジェクト | `projects[].local_path` | `str` | ✅ | - | クローンのルート絶対パス | - |
| 監視対象プロジェクト | `projects[].wiki_base` | `str` | ✅ | - | 当該プロジェクトの Wiki の場所 | raw URL（`https://` 始まり）またはローカル絶対パスのどちらでもよい ※2。エージェントのセッションには SessionStart フックが `WIKI_BASE` として展開 |
| ai-monitor Wiki | `ai_monitor_wiki_base` | `str` | ✅ | - | ai-monitor 自身の Wiki の場所 | 共通対応表・共通ルール・フェーズページの取得元。`projects[].wiki_base` と同じく raw URL / ローカル絶対パスのどちらでもよい ※2 |
| エージェント別モデル | `agents` | `dict[str, AgentModel]` | ✅ | - | エージェント名 → モデル設定 | キーはエージェント名（スキル名・tmux セッション名の一部）。**全 17 エージェント分のエントリ必須**。欠落 / 空値は起動時にバリデーションエラー ※1 |
| モデル | `agents[].model` | `str` | ✅ | - | 起動時の `claude --model` に渡す値 | 短縮名（`opus` / `sonnet` 等。指定した系列の最新版に追従する）または完全 ID（`claude-opus-4-8` 等）。空文字は不可・バリデーションは値の存在のみ |

※2 Wiki の場所の指定

ベースの形で読み方が決まる。
`http://` / `https://` で始まればネットワーク経由、それ以外はローカルファイルとして読む（[ソース読み取り選択](../モジュール構成/注入/URLドキュメント.py.md#ソース読み取り選択)）。

| 指定 | 読み方 | 使いどころ |
| --- | --- | --- |
| `https://raw.githubusercontent.com/{owner}/{repo}/master/docs/wiki` | ネットワーク経由 | master の内容を正とする運用。別マシン・リモート実行 |
| `/home/user/repo/{repo}/docs/wiki` | ローカルファイル | push とキャッシュ待ちなしで反映したい運用。単一マシンでの開発 |

ローカルを指す場合は worktree ではなくメインリポジトリのパスを指定する（フェーズや規約の正は master にあるため）。

## settings.e2e.yaml

| 論理名 | キー | 値 | 説明 | 補足 |
| --- | --- | --- | --- | --- |
| GitHub Token | `github_token` | sandbox 用の PAT | 疎通テストを sandbox の権限だけで実行する | 秘匿 |
| 監視対象プロジェクト | `projects[]` | sandbox（`shuhei1101/ai-monitor-e2e`）のみ | 疎通テストの fixture が `local_path` を CWD に使う | - |

## config/agent_phases.yaml

エージェント名をキーに、起動プロンプトへ載せるフェーズページを並び順で持つ。
モニターが起動時とコンパクト再送時に読む（[エージェントドキュメント](../モジュール構成/モニター/エージェントドキュメント.py.md)）。

| 論理名 | キー | 型 | 必須 | 既定値 | 説明 | 補足 |
| --- | --- | --- | --- | --- | --- | --- |
| フェーズ一覧 | `{エージェント名}` | `list[str]` | ✅ | - | フェーズページのパス一覧 | キーはエージェント名。全エージェント分のエントリが必要 |
| フェーズページ | `{エージェント名}[]` | `str` | ✅ | - | `docs/wiki/` からの相対パス | 並び順がそのまま注入順。先頭にフェーズ索引（`エージェント/{名前}/README.md`）を置く |

記述例:

```yaml
subsystem-conductor:
  - エージェント/subsystem-conductor/README.md
  - エージェント/subsystem-conductor/フェーズ/初期処理.md
  - エージェント/subsystem-conductor/フェーズ/要件確定（初回）.md
```
