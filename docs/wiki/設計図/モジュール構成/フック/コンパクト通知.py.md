# モジュール構成: フック / コンパクト通知

`コンパクト通知` ドメイン（フック側）に属する構成要素詳細。
Claude Code の `PostCompact` フックとして起動し、モニターへコンパクトの発生を知らせる。

自分が誰かは環境変数から知る。
モニターが tmux 起動時に `AI_MONITOR_PROJECT` / `AI_MONITOR_AGENT` / `AI_MONITOR_NUMBER` / `AI_MONITOR_PORT` を渡しており、フックのプロセスはそれを継承する（[起動環境変数](../モニター/エージェント管理.py.md#起動環境変数)）。

通知だけを行い、ドキュメント本体はモニターが送る。
フックの出力は 10,000 文字で打ち切られるため、数万文字のドキュメントを載せられない。

- 参考: [Claude Code フック](https://code.claude.com/docs/ja/hooks)（イベント一覧・入力 JSON・出力の上限・環境変数の継承）

## `hooks/post-compact/notify_compaction.py`
> 種別: ファイル

`PostCompact` で起動し、モニターの[コンパクト通知](../../バックエンド結合/コンパクト通知.py.md)を叩くスクリプト。

---

### メイン
> 物理名: `main`<br>
> 種別: 関数

環境変数から自セッションの素性を組み立て、モニターへ POST する。

#### 引数

なし

引数例:

```python
main()
```

#### 戻り値

| 型 | 説明 | 補足 |
| --- | --- | --- |
| `int` | 終了コード | 常に `0`（フックの失敗でエージェントを止めない） |

戻り値例:

```python
0
```

#### 処理

1. `AI_MONITOR_PROJECT` / `AI_MONITOR_AGENT` / `AI_MONITOR_NUMBER` / `AI_MONITOR_PORT` を読む
   - いずれかが欠けている場合、何もせず `0` を返す（モニター起動でないセッションでは発火させない）
2. `http://127.0.0.1:{ポート}/compaction` へ `project` / `agent_name` / `number` を JSON で POST する
3. 応答にかかわらず `0` を返す
   - 通信に失敗した場合も握りつぶす（再送が届かないだけで、エージェントは手順を失っても次の状態変化で再開できる）

#### 例外

なし

#### 単体テスト

セットアップ:

| セットアップ | 説明 | 補足 |
| --- | --- | --- |
| 環境変数 | 4 変数を `monkeypatch.setenv` で与える | fixture 名 `hook_env` |

| テスト名 | 正常/異常 | 概要 | 条件 | Mock | 期待値 | 補足 |
