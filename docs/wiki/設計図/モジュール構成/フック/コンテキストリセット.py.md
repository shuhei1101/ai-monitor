# モジュール構成: フック / コンテキストリセット

`コンテキストリセット` ドメイン（フック側）に属する構成要素詳細。
Claude Code の `PreCompact` フックとして起動し、モニターへリセットを要求したうえでコンパクト自体をブロックする。

自分が誰かは環境変数から知る。
モニターが tmux 起動時に `AI_MONITOR_PROJECT` / `AI_MONITOR_AGENT` / `AI_MONITOR_NUMBER` / `AI_MONITOR_PORT` を渡しており、フックのプロセスはそれを継承する（[起動環境変数](../モニター/エージェント管理.py.md#起動環境変数)）。

要求だけを行い、ドキュメント本体はモニターが送る。
フックの出力は 10,000 文字で打ち切られるため、数万文字のドキュメントを載せられない。

手動 `/compact` と自動（コンテキスト上限）を区別しない。
どちらも「コンテキストが上限に達した」と同じ扱いにすることで、`/compact` の送信で本番と同じ経路を検証できる。

- 参考: [Claude Code フック](https://code.claude.com/docs/ja/hooks)（イベント一覧・入力 JSON・出力の上限・環境変数の継承）

## `hooks/pre-compact/request_context_reset.py`
> 種別: ファイル

`PreCompact` で起動し、モニターの[コンテキストリセット](../../インターフェース定義/バックエンド/コンテキストリセット.py.md)を叩いてからコンパクトをブロックするスクリプト。

---

### メイン
> 物理名: `main`<br>
> 種別: 関数

環境変数から自セッションの素性を組み立ててモニターへ POST し、コンパクトをブロックする指示を標準出力に書く。

#### 引数

なし

引数例:

```python
main()
```

#### 戻り値

| 型 | 説明 | 補足 |
| --- | --- | --- |
| `int` | 終了コード | 常に `0`（フックの失敗でエージェントを止めない） |

戻り値例:

```python
0
```

#### 処理

1. `AI_MONITOR_PROJECT` / `AI_MONITOR_AGENT` / `AI_MONITOR_NUMBER` / `AI_MONITOR_PORT` を読む
   - いずれかが欠けている場合、何も出力せず `0` を返す（モニター起動でないセッションではコンパクトを通常どおり行わせる）
2. `http://127.0.0.1:{ポート}/context_reset` へ `project` / `agent_name` / `number` を JSON で POST する
3. POST が成功した場合、コンパクトをブロックする JSON（`decision` が `block`）を標準出力に書いて `0` を返す
   - 通信に失敗した場合、何も出力せず `0` を返す（リセットが届かないのにコンパクトも止めると、コンテキストが溢れたまま進んでしまう）

#### 例外

なし
