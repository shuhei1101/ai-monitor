# モジュール構成: フック / 定数展開

`定数展開` ドメイン（フック側）に属する構成要素詳細。
Claude Code の `SessionStart` フックとして起動し、エージェントのセッションに環境変数を展開する。

展開する値は 2 系統ある。
`constants.env` の静的定数（ラベル名 等）と、`settings.yaml` から解決するセッション固有値（リポジトリと Wiki の場所）。

フックは子プロセスとして実行されるため、`export` だけではセッションに残らない。
`CLAUDE_ENV_FILE` へ `export KEY="value"` 形式で追記する。

監視対象外のリポジトリでもセッション自体は開けるようにする。
`settings.yaml` が無い・git remote が無い・対象プロジェクトが未登録のときは、警告を出してセッション固有値の展開だけを飛ばす。

- 参考: [Claude Code フック](https://code.claude.com/docs/ja/hooks)（イベント一覧・`CLAUDE_ENV_FILE` による環境変数の永続化）

## ディレクトリ構成

```
plugins/ai-monitor/
├── constants.env                       # 静的定数（ラベル名 等）の SoT
└── hooks/
    ├── hooks.json                      # SessionStart への登録
    └── session-start/
        └── load-constants.sh           # 展開スクリプト
```

## 定数展開スクリプト
> 物理名: `load-constants.sh`<br>
> 種別: スクリプト<br>
> コンテナ: `hooks/session-start/load-constants.sh`

`SessionStart` で起動し、エージェントが参照する環境変数を `CLAUDE_ENV_FILE` へ追記する。

### 展開する環境変数

| 論理名 | 変数名 | 出所 | 説明 | 補足 |
| --- | --- | --- | --- | --- |
| ラベル名 | `AI_MONITOR_LABEL_*` | `constants.env` | 確認 / 処理中 / 議論中 のラベル値 | コメント行・空行を除いた全行を展開する |
| リポジトリ | `REPO_SLUG` | git remote | CWD のリポジトリ（`owner/name`） | `origin` の URL から導出 |
| プロジェクト Wiki | `WIKI_BASE` | `settings.yaml` | 当該プロジェクトの Wiki の場所 | `projects[]` を `REPO_SLUG` で引いた `wiki_base` |
| ai-monitor Wiki | `AI_MONITOR_WIKI_BASE` | `settings.yaml` | ai-monitor 自身の Wiki の場所 | トップレベルの `ai_monitor_wiki_base` |

### 処理

1. `CLAUDE_ENV_FILE` が未設定の場合、stderr にメッセージを出して終了コード `1` で終わる（展開先が無ければ何もできない）
2. `constants.env` からコメント行・空行を除いた各行に `export ` を前置して `CLAUDE_ENV_FILE` へ追記する
3. `settings.yaml` が無い場合、警告を出して終了コード `0` で終わる（以降のセッション固有値をスキップ）
4. CWD の `git remote get-url origin` からリポジトリ（`owner/name`）を導出する
   - remote が無い場合、警告を出して終了コード `0` で終わる
5. `settings.yaml` から当該リポジトリの `wiki_base` と、トップレベルの `ai_monitor_wiki_base` を読む
   - `projects[]` に当該リポジトリの定義が無い場合、警告を出して終了コード `0` で終わる
6. `REPO_SLUG` / `WIKI_BASE` / `AI_MONITOR_WIKI_BASE` を `CLAUDE_ENV_FILE` へ追記する

### 例外

| 終了コード | 発生条件 | 出力 | 補足 |
| --- | --- | --- | --- |
| `1` | `CLAUDE_ENV_FILE` が未設定 | stderr にメッセージ | 展開先が無く続行できない |
| `0` | `settings.yaml` 不在 / git remote 不在 / プロジェクト未登録 | stderr に警告 | 静的定数だけを展開してセッションは開かせる |

### 補足

- ラベル値の SoT は `constants.env`。本スクリプトは読み替えをせず、行をそのまま `export` に変換する
- Wiki の場所の SoT は `settings.yaml`。モニターが読む値と同一のものをエージェントへ渡すことで、両者が別のベースを見る事故を防ぐ
